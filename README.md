# YouTalk — вёрстка блога и статьи

Статический макет по дизайну Skillfactory: две страницы 

## Структура

```
siite/
├── blog.html          — страница «Блог»
├── article.html       — страница «Статья»
├── css/
│   ├── normalize.css  — сброс стилей
│   ├── style.css      — шапка, подвал, общие компоненты
│   ├── blog.css       — сетка карточек и теги
│   └── article.css    — контент статьи, сайдбар, CTA
├── icons/             — SVG-иконки интерфейса, PNG-иконки из макета
└── images/            — фотографии и иллюстрации (PNG)
```

## Запуск

Откройте `blog.html` или `article.html` в браузере
